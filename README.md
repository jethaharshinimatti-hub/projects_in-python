# CPU Scheduler Simulator

## Overview

CPU Scheduler Simulator is a Python-based project that demonstrates how operating systems schedule processes using different CPU scheduling algorithms. The simulator calculates key performance metrics and visualizes process execution through a Gantt chart.

## Features

* Simulates multiple CPU scheduling algorithms
* Supports process arrival time and burst time inputs
* Generates Gantt charts for process execution
* Calculates Waiting Time, Turnaround Time, and Completion Time
* Compares scheduling performance across algorithms

## Scheduling Algorithms Implemented

* First Come First Serve (FCFS)
* Shortest Job First (SJF)
* Round Robin (RR)
* Priority Scheduling

## Technologies Used

* Python
* Object-Oriented Programming (OOP)
* Matplotlib (for Gantt Chart Visualization)

## How to Run

1. Clone the repository.
2. Install required dependencies.
3. Run the Python file:

   ```bash
   python main.py
   ```
4. Enter process details and view the scheduling results.
